```text
DSC_1842.jpg  →  20260820_Event_001.jpg
IMG_2941.jpg  →  20260820_Event_002.jpg
DSC_2186.jpg  →  20260820_Event_003.jpg
```

ばらばらな名前のファイルを読み込み、順番を整えて、命名ルールを決めるだけ。変更後の名前はその場で一覧に表示され、問題がなければボタン1つで全ファイルに反映されます。

## 主な機能

### 並べた順が、そのまま連番に

撮影日時・作成日・更新日・ファイル名・サイズで並べ替えたあと、ドラッグや `⌘↑`／`⌘↓` で1枚ずつ微調整できます。連番はリストの上から `001`、`002`…と付き、順番を動かした瞬間に変更後の名前も更新されます。

### ブロックを並べるだけの命名ルール

固定の文字はそのまま入力し、ファイルごとに変わる部分だけを「ブロック」として挿入します。よく使う形はプリセットとして保存できます。

| ブロック | 入る内容 | 例 |
| --- | --- | --- |
| 日付 | 撮影日・作成日・更新日（「日付（形式を入力）…」で `YYYYMMDD` などの形式を直接入力もできます） | `20260820` |
| 連番 | 並び順の番号（桁数・開始番号・日付やフォルダごとのリセット） | `001` |
| 元の名前 | 元のファイル名（大文字・小文字の変換も可） | `DSC_1842` |
| 写真情報 | カメラ・レンズ・ISO感度などのEXIF情報 | `ISO800` |

### 実行前に、すべての結果を確認

名前の重複、保存先にある同名ファイル、使えない文字、長すぎる名前は、実行前にエラーとして表示します。問題のあるまま実行されることも、既存のファイルを上書きすることもありません。

### 複数フォルダのファイルを、1つのフォルダへ

別々のフォルダから読み込んだファイルを、名前の変更と同時に1つのフォルダへまとめて移動できます。名前変更ボタン右側の ▾ から「フォルダへ移動…」を選び、選択画面で移動先を指定します（新しいフォルダは「新規フォルダ」ボタンで作成）。「その場で名前を変更」を選べば、ファイルは元の場所にとどまります。移動先で名前が重なる場合も、実行前に知らせます。

### 写真を大きく見ながら

アイコンビューでは、サムネイルと変更前後の名前を並べて確認できます。列数は2〜8列。ダブルクリックかスペースキーで、画像・PDF・動画をクイックルックで開けます。ダークモードにも対応しています。

### 画像の変換とリサイズも同時に

JPEG・PNG・HEICの画像を、名前の変更と同時にJPEGまたはPNGへ変換したり、縦横比を保ったまま長辺を揃えたりできます。元画像は別フォルダに残すことも、確認のうえ置き換えることもできます。

### 似た画像を見つける

まったく同じ画像や、連写などで見た目が似た画像を候補として表示します。比較はMac内だけで行い、勝手に削除や除外はしません。不要なものは、確認画面で選んだファイルだけをゴミ箱へ移動できます。

### いつでも元に戻せる

前回のリネームは `⌥⌘Z` で元に戻し、`⇧⌥⌘Z` でやり直せます。履歴はアプリを終了しても残ります。

### そのほか

- 初回起動時のチュートリアル（ヘルプメニューの「チュートリアルをもう一度表示」でいつでも再表示）
- 複数の命名作業をタブで同時に進める（`⌘T`）
- RAWとJPEGのペアをまとめて同じ名前にする
- 日本語・Englishの表示切り替え（システム設定に合わせることも可能）
- ファイルや利用状況を外部へ送信しない、Mac内で完結する処理

DMG版は、ダウンロードしたDMGを開き、`FileRenamer` を `Applications` フォルダへドラッグしてから起動します。

## 使い方

1. **ファイルを追加** — ツールバーの「ファイルを追加」「フォルダを追加」を押すか、Finderからウインドウへドロップします。
2. **順番を決める** — 並べ替えメニューで基準を選び、必要ならドラッグで調整します。
3. **命名ルールを作る** — プリセットを選ぶか、文字を入力して「ブロックを挿入」で変わる部分を追加します。
4. **確認する** — 一覧の変更後の名前を確認します。緑は実行可能、オレンジは確認事項、赤は修正が必要な項目です。
5. **実行する** — 右下の「○件の名前を変更」を押し、確認画面で内容を確かめて実行します。まとめて移動したい場合は、先に ▾ の「フォルダへ移動…」から移動先を選びます。

外付けドライブなど、アクセス許可が必要な場所の場合だけmacOSのフォルダ選択画面が表示されます。

## よくある質問

### 写真以外のファイルも名前を変更できますか？

はい。PDF、動画、音声、Office文書なども変更できます。画像の変換とリサイズはJPEG・PNG・HEIC／HEIFが対象で、RAW画像は名前の変更と写真情報の利用に対応します。

### 読み込んだだけでファイルが変更されることはありますか？

ありません。実行ボタンを押し、確認画面で実行した項目だけが変更されます。

### 同じ名前になるファイルがある場合はどうなりますか？

実行前にエラーとして表示されます。既存のファイルを黙って上書きすることはありません。

### 似た画像の候補に出た写真は削除されますか？

自動では削除されません。必要な場合だけ、利用者が選んだファイルをFinderのゴミ箱へ移動します。検出は「FileRenamer」→「設定…」から無効にできます。

### アップデートはどう確認しますか？

DMG版は「FileRenamer」→「アップデートを確認…」から確認できます。自動確認は「設定…」でオンにできます。App Store版はApp Storeからアップデートされます。

## 安心して使うための工夫

ファイル名の変更は取り消しが難しい操作なので、失敗しても元の状態に戻せることを最優先に設計しています。

- **2段階のリネーム**：すべてのファイルをいったん一時的な名前へ移してから最終的な名前に確定します。`A↔B` のような名前の入れ替えや、大文字・小文字だけの変更も安全に行えます。
- **途中で失敗しても元に戻す**：実行中にエラーが起きた場合は、完了済みの変更を逆順に戻します。戻せなかったファイルがある場合も、その状態を履歴に残し、あとから「元に戻す」で復元できます。
- **クラッシュ復旧**：処理の進み具合を1ファイルごとに記録しているため、途中でアプリやMacが終了しても、次回起動時に元の名前へ復元します。
- **画像のバックアップ**：画像を変換・リサイズする場合は、元のデータとメタデータを退避してから書き換えます。
- **表記ゆれも衝突として検出**：macOSの標準的なディスクと同じく、大文字・小文字やUnicodeの表記の違い（NFC／NFD）を同じ名前として扱って衝突を判定します。
- **名前の変更では中身に触れない**：通常のリネームはファイルの内容を読み書きせず、名前だけを変更します。
- **Mac内で完結**：ファイル、画像、名前、利用状況を外部へ送信しません。DMG版のアップデート確認でも、新しいバージョンの有無を確認するだけです。
